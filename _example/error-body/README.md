## Typed Error Body Example

End-to-end example of `tanukirpc.WithErrorBody` paired with the
gentypescript static analyzer and a tiny React frontend that consumes the
generated `client.ts`.

The server defines an `ErrorBody` struct (`message`, `status`, `code`) and a
marshaler that maps any handler error to it. The marshaler's return value
becomes the entire response body — there is no `{"error": ...}` envelope, so
the wire shape is exactly the struct.

- `main.go` — router setup, the `ErrorBody` type, the `buildErrorBody`
  marshaler, and a `GET /api/users/{id}` handler that emits
  `404 USER_NOT_FOUND` when the user is missing.
- `frontend/src/client.ts` — generated by gentypescript. Exports the typed
  `ErrorResponse` and the `isErrorResponse` predicate the frontend uses.
- `frontend/src/App.tsx` — a one-screen UI that fetches an id of your
  choice, narrows the response with `isErrorResponse`, and renders either
  the typed user or the typed error.
- `main_test.go` — asserts the runtime wire shape from Go.
- `Taskfile.yml` — drives the local dev loop ([go-task]).

[go-task]: https://taskfile.dev/

### Requirements

- Go 1.25 or later
- [Bun] 1.1 or later (Vite + React frontend)
- [go-task] (`task`) 3 or later

[Bun]: https://bun.sh/

### Quick start

```bash
$ task dev
```

`task dev` boots two things in parallel:

- The Go server through `tanukiup`. `tanukiup` binds the user-facing port
  (`127.0.0.1:8080`) and forwards requests to the child Go binary over a
  unix domain socket — rebuild/restart never races the TCP port.
- The Vite dev server for the frontend, which hot-reloads the UI.

`tanukiup` is also the **single entry point**: routes the Go server
registers (here, `/api/users/{id}`) are forwarded to the child over UDS,
and everything else falls through to Vite via `-catchall-target`. The
browser therefore only ever talks to `127.0.0.1:8080`, so there is no
CORS preflight and Vite doesn't need to know the API route map.

Open <http://127.0.0.1:8080>. Type `1` or `2` for existing users, or
`999` (or any unknown id) to see the typed 404.

### Other tasks

```bash
$ task             # list available tasks
$ task generate    # regenerate frontend/src/client.ts via gentypescript
$ task test        # run the Go tests
$ task lint        # go build + frontend biome lint
$ task build       # build the Go binary and the production frontend bundle
$ task server      # only the Go server (tanukiup hot-reload)
$ task frontend    # only the Vite dev server
```

### Smoke test from the shell

```bash
$ curl -i -H 'Accept: application/json' http://127.0.0.1:8080/api/users/1
$ curl -i -H 'Accept: application/json' http://127.0.0.1:8080/api/users/999
```

The 404 response body is:

```json
{"message":"user not found: id=999","status":404,"code":"USER_NOT_FOUND"}
```
